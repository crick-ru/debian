# fdk-aac (Debian Trixie - Wayland Build)

Debian packaging recipe for `fdk-aac`, optimized for pure Wayland environments without legacy X11 / Xwayland dependencies.

- **Target OS**: Debian GNU/Linux 13 (trixie)
- **Architecture**: `amd64`
- **Component**: `non-free`
- **Maintainer**: crick <mail@crick.ru>

## Configuration Highlights

- Fraunhofer FDK AAC library (`non-free` component) providing high-quality AAC encoding/decoding.
