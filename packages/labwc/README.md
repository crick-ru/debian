# labwc (Debian Trixie - Wayland Build)

Debian packaging recipe for `labwc`, optimized for pure Wayland environments without legacy X11 / Xwayland dependencies.

- **Target OS**: Debian GNU/Linux 13 (trixie)
- **Architecture**: `amd64`
- **Component**: `backports`

## Configuration Highlights

- Pure Wayland compositor without Xwayland (`-Dxwayland=disabled`).
