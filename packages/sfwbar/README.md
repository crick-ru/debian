# sfwbar (crick Debian backports)

Сборка `sfwbar` 1.0~beta17 для Debian 13 (trixie): плавающая панель задач для
Wayland-композиторов.

Упаковка взята из Debian (`sfwbar_1.0~beta13-1`, ветка unstable) и переработана.

## Включено

- Протоколы layer-shell и foreign-toplevel — панель работает со всеми
  композиторами, которые их поддерживают (Sway, Hyprland, labwc и др.).
- Собирается против `libgtk-3-dev` этого репозитория (стадия CI 3), поэтому в
  бинарь не попадают ссылки на `gdk_x11_*`, отсутствующие в публикуемой
  `libgtk-3.so.0`. Сам `sfwbar` X11-API GTK не использует вовсе.

## Отключено

- Man-страница не генерируется: `rst2man`-шаг для `doc/*.rst` не вызывается в
  `debian/rules`, `python3-docutils` не входит в `Build-Depends`. Готовых страниц
  в tar-боле нет, поэтому `man sfwbar` не документирован.
- X11 нигде не нужен: ветки X11 из исходников просто не активируются
  в Wayland-сессии, зависимостей от X11 в пакете не остаётся.

## Изменено

- Версия: `1.0~beta17-3+crick` (ревизия 3 — без quilt-патчей, ставших no-op к 1.0~beta17).
- Патчей quilt нет. Debian-пакет `sfwbar_1.0~beta13-1` содержит в серии три патча
  (исправление опечаток в документации и примере конфигурации, а также
  `python` → `python3` во встроенных скриптах), однако к `1.0~beta17` апстрим
  включает все эти правки, и патчи становятся no-op — `dpkg-source -b`
  отказывается собирать исходный пакет с таким патчом. Правки Debian
  присутствуют в нашей сборке из самого тарболла.
- `override_dh_install` дополнительно удаляет `usr/share/sfwbar/icons/weather/LICENSE`,
  которая не должна поставляться в пакете.
- Отладочные символы (`-dbgsym`) не собираются и не публикуются.
