# sfwbar

Плавающая панель задач (taskbar) для Wayland-композиторов (layer-shell и
foreign-toplevel протоколы).

## Источник упаковки

Упаковка взята из Debian (`sfwbar_1.0~beta13-1`, ветка unstable) и переработана.
Tarball побайтово совпадает с Debian-овским `sfwbar_1.0~beta13.orig.tar.xz`,
но версия апстрима 1.0~beta17 (новее).

## Версии

- **В trixie:** 1.0~beta8-1
- **В исходной упаковке:** 1.0~beta13-1
- **В нашем репозитории:** 1.0~beta17-3+crick (ревизия 3)

## Содержимое

| Пакет | Содержимое |
|---|---|
| `sfwbar` | `usr/bin/sfwbar` — панель задач |

Один бинарный пакет.

## Что изменено

### Отключено

- **Man-страница:** `rst2man`-шаг удалён из `debian/rules`, `python3-docutils`
  не входит в `Build-Depends`. Готовых man-страниц в tar-боле нет,
  `man sfwbar` не документирован — осознанная плата за правило
  «документация не собирается».
- dbgsym-пакеты не собираются (общее правило `scripts/build-package.sh`).

## Патчи

Нет: `debian/patches/series` отсутствует. Debian-пакет
`sfwbar_1.0~beta13-1` содержал три патча (опечатки в документации,
примере конфигурации, `python` → `python3` во встроенных скриптах), но к
1.0~beta17 апстрим включил все эти правки, и патчи стали no-op.

## Изменения ABI

Приложение, а не библиотека. Нет символьных файлов.

## Важные нюансы

### Сборка против GTK 3 этого репозитория

`sfwbar` собирается против `libgtk-3-dev` этого репозитория (стадия CI 3),
поэтому в бинарь не попадают ссылки на `gdk_x11_*`, отсутствующие в публикуемой
`libgtk-3.so.0`. Сам `sfwbar` X11-API GTK не использует — работает как есть
(код X11 в `src/` за `#ifdef GDK_WINDOWING_X11`).

### X11 в control

Проверка `grep -rniE 'libx(11|ext|render)|libxcb|x11proto|x11-xkb|xvfb|xwayland'`
в `debian/control` даёт пустой результат. X11 в wayvnc не отключается
специально — у пакета просто нет X11-зависимостей.

### Примеры конфигурации

`debian/sfwbar.examples` публикует `auto-attach.py`, `event-watcher` и
`single-output-sway` — это готовые скрипты для размещения рядом с конфигом
wayvnc, а не документация. Сохраняются вопреки общему правилу
«примеры не публикуются» (исключение для конфигурационных файлов).
