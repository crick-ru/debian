# sfwbar (Debian Trixie - Wayland Build)

Debian packaging recipe for `sfwbar`, optimized for pure Wayland environments without legacy X11 / Xwayland dependencies.

- **Target OS**: Debian GNU/Linux 13 (trixie)
- **Architecture**: `amd64`
- **Component**: `backports`

## Configuration Highlights

- Flexible Wayland layer-shell taskbar built for modern Wayland compositors.
