# kmscon (Debian Trixie - Wayland Build)

Debian packaging recipe for `kmscon`, optimized for pure Wayland environments without legacy X11 / Xwayland dependencies.

- **Target OS**: Debian GNU/Linux 13 (trixie)
- **Architecture**: `amd64`
- **Component**: `backports`

## Configuration Highlights

- DRM/KMS terminal emulator running directly on the Linux console without X11 server.
