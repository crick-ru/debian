# dummy-x11

Заглушки X11-клиентских библиотек для систем без X11.

## Источник упаковки

Упаковка написана с нуля для этого репозитория. Исходников нет — пакет
состоит из одной библиотеки-заглушки (`dummy-x11.so`) с симлинками,
настоящей `libxcb` из trixie и диагностического скрипта.

## Версии

- **В trixie:** не упакован (не в trixie)
- **В исходной упаковке:** (написана с нуля)
- **В нашем репозитории:** 1.0-2+crick

## Содержимое

| Файл | Назначение |
|---|---|
| `/usr/lib/x86_64-linux-gnu/dummy-x11.so` | единая библиотека-заглушка |
| `…/libX11.so.6`, `…/libXext.so.6` и др. | симлинки → `dummy-x11.so` |
| `…/libXau.so.6`, `…/libXdmcp.so.6` | симлинки → `dummy-x11.so` (для libxcb) |
| `…/libxcb.so.1` | настоящая библиотека из trixie |
| `/usr/bin/dummy-x11-report` | диагностический скрипт |
| `/usr/share/dummy-x11/gen-stubs` | генератор заглушек |
| `/usr/share/dummy-x11/symbols-*.txt` | списки символов |

## Что изменено

- `Provides` с версиями из trixie для 9 пакетов: `libx11-6`, `libxcb1`,
  `libxcomposite1`, `libxdamage1`, `libxext6`, `libxfixes3`, `libxrandr2`,
  `libxau6`, `libxdmcp6`.
- `Conflicts`/`Replaces` с теми же набором: без них apt установил бы
  настоящие X11-библиотеки из trixie вместе с `dummy-x11`, и подмены не
  произошло бы.
- `dh_shlibdeps` отключён (`-override_dh_shlibdeps` пуст): настоящая
  `libxcb.so.1` ссылается на `libXau`/`libXdmcp`, но их заглушки поставляет
  сам `dummy-x11`, и внешних зависимостей у пакета нет по замыслу.

## Важные нюансы

- **Одна библиотека вместо восьми:** все заглушки собраны в один файл
  `dummy-x11.so` (SONAME тоже `dummy-x11.so`), а имена настоящих библиотек —
  симлинки на него. glibc не грузит один и тот же файл дважды (сверка `dev/inode`).
- **`libxcb` настоящая:** заглушка `libxcb.so.1` не давала браузеру
  запуститься — экспериментально установлено, что нужна настоящая библиотека.
  Взята без изменений из trixie (`libxcb1_1.17.0-2+b1`). Её символы не
  входят в объединение: иначе заглушки `xcb_*` перебили бы реальные функции.
- **Полный список символов:** заглушка экспортирует все символы настоящей
  библиотеки (не только 43, что зовёт браузер), потому что транзитивные
  X11-библиотеки ссылаются на внутренние символы друг друга
  (`_XUnlockMutex_fn` из `libX11.so.6`). 1556 символов собираются в
  `dummy-x11.so`, список `libxcb` (676) — только для отчёта.
- **Ключевые зависимости:** настоящая `libxcb` требует `libXau`/`libXdmcp`
  по `NEEDED` (аутентификация X11), и их заглушки входят в `dummy-x11.so`.
  Функции аутентификации вызываются только при подключении к X-серверу,
  которого в целевой системе нет.

Пакет нужен `yandex-browser-stable`, который без него не запустится и не
установится на системе без X11.
