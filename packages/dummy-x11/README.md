# dummy-x11

Заглушки X11-клиентских библиотек для систем без X11.

## Источник упаковки

Упаковка написана с нуля для этого репозитория. Исходников нет — пакет
состоит из одной библиотеки-заглушки (`dummy-x11.so`) с симлинками,
логирующей заглушки `libxcb.so.1` и диагностического скрипта.

## Версии

- **В trixie:** `libxcb1 1.17.0-2+b1` (список символов для заглушки)
- **В исходной упаковке:** (написана с нуля)
- **В нашем репозитории:** 1.0-9+crick

## Содержимое

| Файл | Назначение |
|---|---|
| `/usr/lib/x86_64-linux-gnu/dummy-x11.so` | единая библиотека-заглушка |
| `…/libX11.so.6`, `…/libXext.so.6` и др. | симлинки → `dummy-x11.so` |
| `/usr/lib/x86_64-linux-gnu/libxcb.so.1` | логирующая заглушка libxcb (все функции → 0/null) |
| `/usr/bin/dummy-x11-report` | диагностический скрипт |
| `/usr/share/dummy-x11/gen-stubs` | генератор заглушек |
| `/usr/share/dummy-x11/gen-libxcb-stub` | генератор логирующей libxcb |
| `/usr/share/dummy-x11/symbols-*.txt` | списки символов |

## Что изменено

rev 9: полное упрощение. Никакого делегирования реальной libxcb.

- `Provides` с версиями из trixie для 9 пакетов: `libx11-6`, `libxcb1`,
  `libxcomposite1`, `libxdamage1`, `libxext6`, `libxfixes3`, `libxrandr2`,
  `libxau6`, `libxdmcp6`.
- `Conflicts`/`Replaces` с тем же набором: без них apt установил бы
  настоящие X11-библиотеки из trixie вместе с `dummy-x11`, и подмены не
  произошло бы.
- `dh_shlibdeps` отключён (`-override_dh_shlibdeps` пуст): заглушки
  `libXau`/`libXdmcp` поставляет сам `dummy-x11`, и внешних зависимостей
  у пакета нет по замыслу.
- **`libxcb — логирующая заглушка без делегирования.** В rev 9 убрано
  `dlopen`/`dlsym`, скрытая real libxcb больше не используется. Все
  функции `xcb_*` возвращают `0`/`NULL`:
  - `xcb_connect`, `xcb_connect_to_display_with_auth_info` → `NULL`
  - `xcb_connection_has_error` → `0` (int)
  - `xcb_generate_id` → `0xffffffff`
  - `xcb_flush`, `xcb_disconnect` → `0`
  - все остальные функции → `0`/`NULL`

## Логгирование libxcb

Логирующая заглушка `libxcb.so.1`:

1. При загрузке открывает файл лога в режиме **append** (`/tmp/dummy-x11-libxcb.log`
   или путь из env `YABROWSER_XCB_LOG`).
2. Для каждого из 676 символов `xcb_*` генерирует функцию-обёртку, которая:
   - захватывает аргументы из регистров (rdi, rsi, rdx, rcx, r8, r9);
   - логгирует вызов (название + аргументы);
   - возвращает заранее определённое значение:
     - `0`/`NULL` для большинства функций (через `ZERO_TEMPLATE`);
     - `0xffffffff` для `xcb_generate_id`;
     - `0` для `xcb_flush`/`xcb_disconnect`;
     - `0` (int) для `xcb_connection_has_error` через `INT_OVERRIDE_TEMPLATE`;
   - логгирует возвращаемое значение;
   - возвращает результат.

## Известные вызовы браузера

Из лога видно, что браузер вызывает 6 функций xcb:

| функция | возвращает | примечание |
|---|---|
| `xcb_connect` | `NULL` | не X11 connection |
| `xcb_connect_to_display_with_auth_info` | `NULL` | не X11 connection |
| `xcb_connection_has_error` | `0` | no error |
| `xcb_generate_id` | `0xffffffff` | валидный XID |
| `xcb_flush` | `0` | пусто |
| `xcb_disconnect` | `0` | void, значение не важно |

## Важные нюансы

- **Одна библиотека вместо восьми:** все заглушки (libX11, libXext, etc.)
  собраны в один файл `dummy-x11.so` (SONAME тоже `dummy-x11.so`), а имена
  настоящих библиотек — симлинки на него. glibc не грузит один и тот же файл
  дважды (сверка `dev/inode`).
- **`libxcb` — логирующая заглушка без делегирования:** все 676 символов
  `xcb_*` экспортируются и возвращают `0`/`NULL`. Список символов взят с
  реальной `libxcb 1.17.0-2+b1`. `NEEDED` — только `libc.so.6`.
- **`libXau`/`libXdmcp` заглушки удалены:** без real libxcb их не нужно.
  Все X11-символы находятся в `dummy-x11.so` и `libxcb.so.1`.
- **Аргументы 7+:** логирующая заглушка захватывает и логгирует все 6
  регистровых аргументов. Аргументы, переданные через стек (функции с >6
  аргументами), логгируются из регистров — стековые аргументы не пересылаются.

Пакет нужен `yandex-browser-stable`, который без него не запустится и не
установится на системе без X11.
