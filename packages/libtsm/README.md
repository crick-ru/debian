# libtsm (Debian Trixie - Wayland Build)

Debian packaging recipe for `libtsm`, optimized for pure Wayland environments without legacy X11 / Xwayland dependencies.

- **Target OS**: Debian GNU/Linux 13 (trixie)
- **Architecture**: `amd64`
- **Component**: `main`
- **Maintainer**: crick <mail@crick.ru>

## Configuration Highlights

- Terminal-emulator state machine library for kmscon.
