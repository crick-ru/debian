# pixman

Библиотека низкоуровневой манипуляции пикселями: регионы (banded rectangles),
композиция (Porter/Duff), геометрические примитивы.

## Источник упаковки

Упаковка взята из Debian (`pixman_0.46.4-1`, ветка unstable) и переработана.
Tarball побайтово совпадает с Debian-овским `pixman_0.46.4.orig.tar.gz`.

## Версии

- **В trixie:** 0.44.0-3
- **В исходной упаковке:** 0.46.4-1
- **В нашем репозитории:** 0.46.4-2+crick (ревизия 2)

## Содержимое

| Пакет | Содержимое |
|---|---|
| `libpixman-1-0` | `libpixman-1.so.0` |
| `libpixman-1-dev` | заголовки, `libpixman-1.pc`, `libpixman-1.so` |

Набор закрытый: `libpixman-1-dev` требует ровно `libpixman-1-0 (= ${binary:Version})`.

## Что изменено

### Отключено

- **GTK-демо:** `-Dgtk=disabled` (как в упаковке Debian).
- **Автодокументация:** удалены `*.la`-файлы и `*.md5` из staging-дерева.
- dbgsym-пакеты не собираются (общее правило `scripts/build-package.sh`).

### Нет изменений (сохранено как есть)

- **libpixman-1-0-udeb** — в репозиторий не попадает (`scripts/build-package.sh`
  собирает только `*.deb`).

## Патчи

Нет собственных патчей (quilt). Есть один патч Debian
`test-increase-timeout.diff` — он относится к тестам, которые не собираются
(не запускаются), но применяется `dpkg-source` автоматически.

## Изменения ABI

SONAME не меняется (`libpixman-1.so.0`), файл меняется с `libpixman-1.so.0.44.0`
на `libpixman-1.so.0.46.4`. Добавлены новые символы (включая
`PIXMAN_a16b16g16r16` — 64-битный формат, который нужен wlroots 0.20.2),
удалённых нет. Заголовочные макросы сверены между 0.44.0 и 0.46.4 — cairo, GTK
и другие клиенты работают без пересборки.

## Важные нюансы

### Зачем нужен

`wlroots 0.20.2` требует `pixman >= 0.46.0` для макроса `PIXMAN_a16b16g16r16`
(единственный нужный 64-битный формат). В trixie pixman 0.44.0 — его нет.

### Формат исходников

`scripts/build-package.sh` принудительно ставит `3.0 (quilt)` как формат
источников (строка 51), поэтому из `debian/rules` убран add-on `--with quilt`:
иначе патчи применяются дважды. Патч
`test-increase-timeout.diff` накладывается `dpkg-source` один раз.

### apt upgrade

В trixie от `libpixman-1-0` зависят 62 пакета. Все продолжают работать
без пересборки (SONAME и набор символов сохранены).
